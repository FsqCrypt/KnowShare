项目描述：考虑通用平台更偏泛娱，不利于知识内容的沉淀和获取，所以设计了面向知识分享的平台，支持用户发布知识， AI生成摘要、点赞 /收藏，关注取关、首页feed展示。通过缓存优化、异步等方案，提高系统的并发和高可用需求。
技术栈：Spring Boot、Spring Security、Spring AI、MySQL、Redis、Kafka、Caffeine、阿里OSS、Canal、Elasticsearch。	认证系统：基于 Spring Security + JWT 实现双令牌认证体系，结合 Redis 刷新令牌白名单，支持15分钟访问令牌+7天刷新令牌的安全会话管理，并支持令牌即时撤销，兼顾安全性与性能。
计数系统：针对笔记维度的点赞/收藏 和用户维度的关注/取关，以 Redis作为底层存储，采用定制化 Redis SDS 二进制紧凑计数，通过Lua脚本保证计数更新的原子性。
发布系统：采用渐进式发布流程，图片、Markdown等内容存储至阿里云OSS，通过后端生成预签名+前端直传的方式完成上传，降低服务端传输压力；同时接入DeepSeek AI自动生成文章摘要。
用户关系系统：实现关注/取关功能，采用一主多从 + 事件驱动架构，将粉丝表、计数系统和列表缓存作为关注表的伪从。关注时，通过Outbox + Canal + Kafka 异步驱动下游数据更新，保证最终一致性与扩展性。
点赞系统：采用异步写+写聚合的方式应对高并发写场景，基于位图实现点赞状态的幂等控制与快速判重；当读取异常或数据缺失时，可基于位图按需重建，保证最终一致性。
首页Feed流：设计三级缓存架构，Caffeine本地缓存+ Redis 页面缓存+Redis片段缓存；结合自定义hotkey探测机制、分层续期、随机抖动和single-flight单飞锁，降低热点回源与缓存雪崩风险。
搜索系统：基于Elasticsearch构建内容搜索，支持关键词检索，标签过滤，采用游标分页保证深分页稳定性。
